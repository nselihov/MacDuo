# MacDuo

MacDuo показывает, как изображение на экране MacBook складывается вместе с крышкой. Когда вы закрываете ноутбук, рабочий стол словно остаётся на месте: уходит в перспективу, размывается и постепенно исчезает. При открытии всё происходит в обратном порядке.

Эффект работает на рабочем столе и экране блокировки. Для каждого из них его можно включить отдельно. Если подключён внешний монитор, анимация остаётся на экране MacBook.

Пока это бета-версия. Она проверена на одном MacBook; на других моделях и версиях macOS работа может отличаться. Для эффекта рабочего стола macOS попросит доступ к записи экрана. MacDuo не сохраняет и никуда не отправляет изображение.
