# MacDuo

Экспериментальное приложение для macOS: интерфейс визуально остаётся в пространстве, пока крышка MacBook движется вокруг него.

## Что уже работает

- нативное приложение для macOS без веб-обёртки;
- интерактивное превью пространственного складывания;
- ручной ползунок угла крышки;
- чтение реального датчика крышки на совместимом MacBook;
- живой захват встроенного дисплея для мини-превью через ScreenCaptureKit по явному действию пользователя;
- отдельный полноэкранный overlay на дисплее MacBook, не перехватывающий клики;
- интерполяция показаний датчика во время движения и захват до 60 кадров в секунду;
- сохраняемая калибровка точек начала и завершения эффекта;
- живое изображение, которое сохраняет часть исходного положения при перспективном складывании; блюр нарастает от шарнира к свободному краю;
- широкое растворение верхнего края в фоне, усиливающееся при закрытии;
- автоматическое восстановление датчика и живого захвата после сна;
- безопасная реакция на подключение монитора, смену разрешения, clamshell-режим и зеркалирование;
- автоматические проверки математики анимации.

MVP не сохраняет видео и не отправляет содержимое экрана: кадры обрабатываются только в памяти Mac. Для живого превью macOS всё равно требует системное разрешение «Запись экрана».

Проект рассчитан на конфигурацию с двумя мониторами: полноэкранный эффект применяется только к встроенному дисплею MacBook, даже если главным назначен внешний монитор. Внешний монитор и его расположение в macOS приложение не меняет.

После сна MacDuo не использует старый кадр: он ждёт, пока macOS заново соберёт конфигурацию экранов, повторно находит Built-in Retina Display и только затем восстанавливает захват. В clamshell-режиме и при зеркалировании эффект временно отключается. Когда встроенный экран снова становится отдельным активным дисплеем, прежнее включённое состояние восстанавливается автоматически.

На экране блокировки доступен эксперимент «Анимация крышки»: системный живой
блюр усиливается при закрытии крышки от шарнира к свободному краю, а изображение
смещается в перспективе. Под эффектом остаётся настоящий локскрин,
включая аватар и форму входа. Изображение обоев не подставляется; снимки локскрина
и ввод пароля приложение не получает. Окно пропускает ввод в macOS.

Окно подготавливается заранее и при закрытии остаётся в WindowServer на время сна.
Датчик восстанавливается сразу при пробуждении экрана. Если свежий угол задержался,
слой освобождает экран; позднее открытие не запускает эффект заново. При остановке
крышки эффект остаётся на текущем угле, пока датчик продолжает давать показания.

На рабочем столе теперь работает отдельный Metal-рендер по мотивам
[iPhone Duo Animation](https://github.com/akashtdev/iphone-duo-animation/):
содержимое складывается в перспективе вместе с плоскостью экрана, а размытие
усиливается от шарнира к свободному краю. Он обрабатывает локальные кадры
ScreenCaptureKit; для показа эффекта нужно подключить рабочий стол в приложении.
Старый рендер рабочего стола можно временно вернуть запуском с флагом
`--legacy-desktop-renderer`. Эксперимент локскрина и мини-превью пока используют
прежний рендер и общие сохранённые настройки. Это разные графические пути:
экран пароля нельзя подать в Metal через обычный захват рабочего стола.
Лицензия исходного проекта включена в `Resources/Licenses/iPhoneDuoAnimation.txt`.
Внутренние SkyLight и Core Animation API могут измениться после обновления macOS. Эффект не работает
на этапе FileVault до запуска приложения. Обычный захват рабочего стола
останавливается на время блокировки и восстанавливается после разблокировки.
Подробности: [эксперимент локскрина](docs/LOCK_SCREEN_EXPERIMENT.md).

## Как запустить

Для обычного запуска скачайте `MacDuo-preview.dmg` из
[бета-релиза](https://github.com/nselihov/MacDuo/releases/tag/v0.2.1-beta.1),
откройте образ, перетащите `MacDuo.app` на ярлык «Программы» и затем откройте
MacDuo из папки «Программы».
В главном окне находятся статус и два переключателя: «Рабочий стол» и «Экран
блокировки». Значок в строке меню позволяет переключить оба режима, открыть
основное окно или диагностику и завершить приложение. Закрытие окна не
останавливает MacDuo. Запуск при входе включается в настройках по вашему
выбору; по умолчанию он выключен. Приложение запоминает выбранные режимы.

Чтобы пересоздать установочный образ после сборки, выполните
`./scripts/package-dmg.sh`.

Для разработки откройте Terminal в папке проекта и выполните:

```bash
./scripts/run.sh
```

Первый запуск может собираться немного дольше следующих. Чтобы только проверить код:

```bash
./scripts/test.sh
```

Скрипты используют установленный Xcode 27 и не зависят от старого Command Line Tools SDK.

Бета-сборка подписана локально и пока не нотарифицирована Apple. На другом Mac
macOS может потребовать отдельного разрешения на запуск. Датчик крышки и часть
эффекта экрана блокировки используют недокументированные системные интерфейсы;
их работу после обновления macOS нужно проверять заново.

## Первый запуск эффекта

Включите «Рабочий стол» и медленно прикройте крышку. Для экрана входа включите
«Экран блокировки». Превью, калибровка и тонкие параметры находятся в отдельном
окне «Диагностика», которое открывается через настройки или строку меню.

Если macOS ещё не дала доступ к изображению экрана:

1. Включите «Рабочий стол» и нажмите «Разрешить доступ к экрану» в MacDuo.
2. Подтвердите доступ в окне macOS.
3. Завершите MacDuo через значок в строке меню и откройте снова из «Программ».
4. Если рабочий стол не подключился автоматически, выключите и снова включите
   его переключатель.

При проверке с внешним монитором оставьте окно MacDuo на нём. Полноэкранный
слой должен появляться только на экране ноутбука.

## Как откалибровать точки

Откройте «Настройки → Диагностика» и разверните «Калибровка и настройка».

1. Полностью откройте крышку и нажмите «Запомнить открыто».
2. Прикройте крышку до положения, где эффект уже должен завершаться, но Mac ещё не засыпает.
3. На внешнем мониторе нажмите «Запомнить финиш».

Точки сохраняются между запусками. Кнопка «Сбросить» возвращает исходные значения 115° и 25°.

## Важное ограничение

Датчик угла крышки доступен через недокументированный HID-интерфейс macOS. Поэтому проект подходит для эксперимента и прямой установки, но не рассчитан на Mac App Store.
