# Ближайшие задачи

MacDuo 0.2.1 — публичная бета для прямой установки на совместимом MacBook.
Эффект рабочего стола, экран блокировки и восстановление после сна проверены
на одном устройстве. Поддержка других моделей и версий macOS пока требует
отдельной проверки.

- Проверить установку и оба эффекта на другом MacBook, включая разрешение на
  захват экрана, блокировку и выход из сна.
- Проверить сочетания встроенного и внешнего мониторов: основной экран,
  зеркалирование, подключение на ходу и clamshell.
- Измерить расход ресурсов при неподвижной открытой крышке и в длинной сессии.
- Подготовить подпись Developer ID и нотарификацию перед широкой раздачей.

Ограничение: датчик крышки и часть показа на экране блокировки используют
недокументированные API macOS. После обновления системы работа эффекта может
измениться, поэтому оба режима нужно проверить заново на устройстве.
